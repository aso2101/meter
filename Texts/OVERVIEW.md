# Methods

## Symbols

Authors refer to groups of light and heavy syllables by different symbols. The basic terminology was introduced by Piṅgala, who uses the following (G represents a heavy syllable [*guru*] and L represents a light syllable [*laghu*]).

|------------|-----------|
| **symbol** | **value** |
|------------|-----------|
| ma         | GGG       |
| ya         | LGG       |
| ra         | GLG       |
| sa         | LLG       |
| ta         | GGL       |
| ja         | LGL       |
| bha        | GLL       |
| na         | LLL       |
| ga         | G         |
| la         | L         |
	
These symbols can be memorized with the mnemonic *yamātārājabhānasalagaṁ* (which however appears to have been invented after Piṅgala), where the first letter represents the weight pattern (light or heavy) of the three syllables that follow it.

Authors can use either the akārānta version of these symbols or the non-akārānta version depending on metrical convenience (e.g., raḥ or r), and they can be combined, e.g. bhmaḥ = GLLGGG, nau = LLLLLL, and so on.

For referring to the position of obligatory word-breaks (yati) in a line, authors generally use the *bhūtasaṅkhyā* system. This is a system in which something that is found in a certain number (e.g., “oceans,” of which there are four in Sanskrit) is used to refer to that number. Hence *r̥ṣi* will mean “seven,” and the word-break falls after the seventh syllable.

1. Definitions (anuṣṭubh)
